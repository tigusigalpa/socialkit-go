# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of this package.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly.

- **Email:** sovletig@gmail.com

Please **do not** open a public GitHub issue for security vulnerabilities.

Include as much of the following information as possible in your report:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Affected versions, if known.
- Any suggested mitigations or fixes.

You should receive an acknowledgement within 72 hours. Please allow reasonable
time for investigation and a fix to be developed before any public disclosure.

## Disclosure

We kindly request that you:

- Give us reasonable time to investigate and remediate the issue before
  disclosing it publicly.
- Avoid accessing or modifying data that does not belong to you.
- Act in good faith to avoid degrading the experience of other users.
